Trabajo Práctico N°2 - ToDo List / Task Manager
Descripcion
Aplicación web de gestión de tareas desarrollada con HTML, CSS, Bootstrap y JavaScript Vanilla.
La aplicación permite crear, listar, editar, eliminar y marcar tareas como completadas utilizando JSON Server como backend falso.

Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript Vanilla
- JSON Server
- Git y GitHub

  Funcionalidades

- Listar tareas desde JSON Server.
- Agregar nuevas tareas.
- Editar tareas existentes.
- Eliminar tareas.
- Marcar tareas como completadas.
- Filtrar tareas completadas y pendientes.
- Buscar tareas.
- Diseño responsive.
- Manipulación dinámica del DOM.
